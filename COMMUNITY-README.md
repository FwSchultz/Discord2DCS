# Discord2DCS Community Client 0.10.0-beta-rc2

## Deutsch – Schnellstart

1. ZIP vollständig entpacken.
2. `INSTALL.bat` doppelklicken.
3. Sprache wählen.
4. Serveradresse vom Community-Admin eingeben.
5. persönlichen Pairing-Code eingeben.
6. optional Windows-Autostart aktivieren.
7. DCS komplett neu starten.
8. `Strg + Shift + D` öffnet/schließt das Overlay.

Unter **DCS → Einstellungen → Spezial → Discord2DCS** kannst du das Modul, den automatischen Overlay-Start, Systemmeldungen und die Sprache einstellen.

Installation: `%LOCALAPPDATA%\Discord2DCS`

Support-Logs:

```text
%LOCALAPPDATA%\Discord2DCS\pc-client\Discord2DCS-Client.log
%USERPROFILE%\Saved Games\DCS*\Logs\Discord2DCS.log
```

## English – Quick start

1. Fully extract the ZIP.
2. Double-click `INSTALL.bat`.
3. Choose the language.
4. Enter the server address supplied by your community admin.
5. Enter your personal pairing code.
6. Optionally enable Windows autostart.
7. Restart DCS completely.
8. `Ctrl + Shift + D` toggles the overlay.

Use **DCS → Options → Special → Discord2DCS** to enable/disable the module, control overlay startup/system messages and select the language.

Installation: `%LOCALAPPDATA%\Discord2DCS`
